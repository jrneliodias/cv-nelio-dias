# Exemplos de referência para tailor-resume-to-job

## Títulos por tipo de vaga

- Frontend: "Desenvolvedor Frontend Pleno | React, Next.js, TypeScript"
- Backend Node: "Desenvolvedor Backend Node.js Pleno | TypeScript, NestJS, Prisma"
- Full Stack: "Desenvolvedor Full Stack Pleno | Node.js, React, TypeScript, PostgreSQL"
- Python/Django: "Desenvolvedor Backend Python Pleno | Django REST Framework, PostgreSQL, AWS"

Regra geral: só coloque no título tecnologias que são centrais para a vaga-alvo, mesmo que o profissional saiba outras.

## Skills — frases de "familiaridade" honesta

- "Fastify: familiaridade prática em projeto pessoal com rotas, plugins, schemas e estrutura modular."
- "Semgrep: familiaridade com análise estática e práticas de qualidade de código."
- "MySQL: familiaridade com bancos relacionais e consultas SQL."
- "Kafka/RabbitMQ: conhecimento teórico de filas de mensagens; experiência prática com AWS SQS."

## Bullets de experiência — antes/depois

- Antes: "Participei de projetos diversos usando várias tecnologias."
- Depois: "Implementei APIs REST em NestJS + TypeScript com Prisma ORM e PostgreSQL para módulos de autenticação, permissões e notificações."

- Antes: "Domínio total do frontend do sistema."
- Depois: "Desenvolvi componentes React reutilizáveis com TypeScript, seguindo o design system da empresa, para os módulos de checkout e cadastro de usuários."

## Confidencialidade

- Antes: "Cliente MAPFRE, redução de 40% no tempo de carregamento do checkout."
- Depois (se a métrica for defensável e já constava no material original): "Reduzi em ~40% o tempo de carregamento do checkout para cliente do setor de seguros, resultando em aumento de conversão."
- Depois (se a métrica não puder ser confirmada): "Otimizei o tempo de carregamento do checkout para cliente do setor de seguros, com melhoria perceptível na taxa de conversão."

## Ordenação de projetos por tipo de vaga

- Vaga React/Frontend: primeiro projetos com React, Next.js, TypeScript, SPA, SSR, UI/UX, componentização, APIs e testes.
- Vaga Backend Node: primeiro projetos com Node.js, NestJS, TypeScript, Prisma, APIs REST, autenticação, RBAC, testes, Docker e CI/CD.
- Vaga Full Stack Node/React: equilibrar backend Node e frontend React, começando pelos projetos que têm os dois.
- Vaga Python/Django: primeiro projetos com Python, Django REST Framework, APIs, testes, Docker e AWS.

## Correção de nomenclatura técnica

- "React 19" → "React" (salvo se a versão for realmente relevante para a vaga)
- "SvelteKit 5" → "Svelte 5 + SvelteKit" ou apenas "SvelteKit"
- Nunca colocar frameworks backend (ex: NestJS, Express) dentro da categoria "Banco de Dados"
- Separar sempre: Backend / Frontend / Banco de Dados / DevOps / Qualidade / Integrações
